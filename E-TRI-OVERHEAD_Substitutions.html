Swaps

Swaps by situation

# Equipment missing

sub: No cable column

Why: STS doesn't program the French press, so there is no overhead swap off the cable to give. The single arm overhead cable tricep extension is this page's own movement rather than a substitute for it. Use whichever column is free.

Exercises: Single arm overhead cable tricep extension

# The joint path is the problem

sub: Her elbows or shoulders object to a fixed implement

Swap to: Rope on the cable, over any bar

Why: The cable path can be customised to her shoulder. The fix is the implement rather than a cue.

# The overhead position is restricted

sub: She cannot get overhead without the low back arching

Do this: See Watch for, plus Pain rules and when to refer.

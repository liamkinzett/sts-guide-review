Building a session · T-12.14

A top set plus back-offs belongs to the strength path

A top set (top set) followed by lighter back-off sets (back-off set) is the natural shape of a strength session. On the muscle-building path it buys nothing that straight sets (straight sets) matched for volume and effort do not. Use it when the goal is strength, not as a growth tool.

Why it changes by path. On the muscle-building path, no method of overload grows more muscle than another once volume and effort are equated. A top set and its back-offs are one more shape that principle covers. It is not a superior structure there. It is a structure. On the strength path, load is the sensitive lever. A top set expressed near her current maximum, backed off to accumulate volume beneath it, is how a strength session is built. Progression has both rules.

Where it runs, order it the usual way. Heavier and lower rep before lighter and higher rep. That holds for a top set and its back-offs, and for a straight run of working sets at one weight.

So the extra faff is worth it when the goal is strength. It is also worth it when you want her to feel a heavier single without paying for it in every set that follows. It is not worth it as a growth tool over straight sets.

Terms on this page

top set: The heaviest set of the exercise that day. Back-off sets follow it at a lighter load.

back-off set: A lighter set done after the heaviest set of the day. If it sits at four or more reps in reserve, it is not a hard set.

straight sets: Ordinary sets of one exercise: work, rest, work again. Every working set is done at the same weight for the same rep target.

Cueing · T-34.7

A cue that fails has told you something

A cue is a probe. Whether it works or not, you have learned something. Record both.

If "knees out" fixes the position, you have learned the fault was coordination. If it does nothing, you have learned it was not, which narrows the problem to capacity, setup or exercise selection.

So a failed cue is a result, not a wasted set. Record which cue you tried and what happened. The next coach reading her file needs to know what has already been ruled out.

Watch for

Trying six cues in six sets and recording none of them. That is the same information thrown away.

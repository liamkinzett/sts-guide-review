Before you send a program · T-41.2

The program must survive STS's own checks before it survives the client

Before she sees the program, it passes six checks that the rest of this Library already makes. Each one exists because a real program failed it.

Check two: STS's own checks

Volume. Does each muscle's weekly hard sets sit where Volume puts it for her training age?

Effort. Does any compound sit below 1 RIR? Has the fit caveat been applied to any machine work?

Selection. Does every exercise name what it is buying? Is anything there for novelty?

Balance. Is there at least one unilateral movement where One leg or two requires it?

Session shape. Does the order match Building a session?

Approval. Is every exercise on the STS exercise list, named as the list names it?

What each row is asking.

Volume: total each muscle's weekly (hard set) count and compare it with her band in Volume. Look the band up. Volume also caps what one session should put on a muscle.

Effort: no compound sits below 1 (RIR). The fit caveat is Effort and intensity's stability test run on her, in the setup in front of you. A machine only earns true failure if it actually holds her position. A pad that sits wrong on a short client puts the 1 RIR floor back. A tested single at the end of a strength phase sits below the floor by design. The check reads the working sets, not the test.

Selection: Choosing exercises asks every exercise to name what it is buying. Rotation needs a reason, and time served is not one.

Balance: One leg or two says where a single-leg movement is required. Check it is there.

Session shape: Building a session owns the order. Check the order matches it.

Approval: every exercise is on the STS exercise list, under the name the list gives it.

The last row is a real failure mode rather than a formality. The first set of exercise pages ever written taught five movements STS does not program. It took a gate to notice.

Terms on this page

hard set: A working set taken within three reps of failure. It is the only kind of set that counts toward her weekly volume.

RIR: Reps in reserve. How many more reps she could have done when the set stopped. Every STS set is prescribed in it.

Running the gate before you send it

Nothing here is new doctrine. It is this topic's rules in the order you run them, which is the gate itself.

The gate, in order

Test. Two checks in sequence: every slot complete, then STS's own checks.

Read. Start where the writing finished, and read every hole for whether it was declared.

Do. Fix what the checks surface, declare what cannot be fixed, then read it as her.

Change. The program changes until it passes. Nothing else does.

Escalate. Anything she would avoid is a program signal. Delivery belongs elsewhere.

1 · Test. Two checks, in this order. Slot completeness first, because a slot missing a piece cannot be checked against anything else.

Check one: every slot is complete

Load, or a method for selecting it. Never a weight in kilos. Effort and intensity owns it.

Reps. The band the implement sets. Effort and intensity owns it.

Effort, as reps in reserve. Effort and intensity owns it.

Tempo or pause intent, where the movement needs one. Tempo and pauses owns it.

One cue, surviving being done wrong. Cueing owns it.

A substitution, where an equipment problem is likely. Writing program instructions owns it.

Then STS's own checks. Each one exists because a real program failed it.

Check two: STS's own checks

Volume. Does each muscle's weekly hard sets sit where Volume puts it for her training age?

Effort. Does any compound sit below 1 RIR? Has the fit caveat been applied to any machine work?

Selection. Does every exercise name what it is buying? Is anything there for novelty?

Balance. Is there at least one unilateral movement where One leg or two requires it?

Session shape. Does the order match Building a session?

Approval. Is every exercise on the STS exercise list, named as the list names it?

Two notes on the effort row. The fit caveat means a machine only earns true failure if it actually holds her position in the setup in front of you. A pad that sits wrong on a short client puts the 1 RIR floor straight back. And a tested single at the end of a strength phase sits below 1 RIR by design. The effort check reads the working sets, never the test.

2 · Read. Where completeness fails first is the last two exercises of the last session. Attention runs out in the same order the program was written, so start the check where the writing finished.

Then read every hole for whether it was declared. A gap you have declared is complete. A gap you have left silent is not. A coach reading the program next month cannot tell an absent decision from an unmade one. She will assume it was made.

3 · Do. Fix what the two checks surface. Then declare what cannot be fixed. A slot with no substitution because none exists says so in writing. A tempo chosen without an exercise page to justify it says so too.

Then the one step no checklist replaces. Open the program as though you had never seen it and did not know the reasoning.

Read it as her

Do I know what to do on every line? Every slot carries its intent, not just its numbers.

Do I know how heavy? Effort and intensity writes a method for finding the load, never a number in kilos.

Do I know how hard? The reps in reserve are written on every set.

If the machine is taken, do I know what to do? The substitution is in the notes already.

Is there anything here I would avoid? Adherence as a signal reads that as a program signal, not a character flaw.

It is the only step that catches a program which is technically complete and practically unusable.

4 · Change. The program changes until it passes. Nothing else does. A program is not fit to assign until every slot is complete. A slot missing any of the elements is a suggestion rather than a slot.

5 · Escalate. Anything she would avoid is read as a program signal by Adherence as a signal. Every check above points at the topic that owns its answer, and a failure is fixed there rather than argued with here. Trainerize, scheduling and how the program reaches her belong to the delivery guide.

Terms on this page

RIR: Reps in reserve. How many more reps she could have done when the set stopped. Every STS set is prescribed in it.

Choosing exercises · T-13.20

A lagging muscle gets an order of elimination, not a single test

Do not look for one test that separates "she is built that way" from "she is performing it wrong". Work through an order instead. Execution first, structure last.

Eliminate in this order

Rule out execution first. An exercise trains the muscle assigned to it only if she performs it that way. Watch the footage of every movement meant to target the lagging muscle before concluding anything else. A rear-foot-elevated split squat is glute work if she hinges and descends into the bottom. Performed upright, the same exercise loads quads. This is free. It is also the most common actual explanation.

Check structure only after execution clears, as a hypothesis, not a verdict. Structure only indicates what a muscle will do. Position dictates it. No client has ever walked in and matched exactly what her proportions predicted. Most people sit in the middle of the bell curve, which is how bell curves work.

Run the dosing ladder before reaching for her build as the explanation. Move the lagging muscle fresh in the session first, since that costs nothing. Add volume if the sets are cheap on whole-body fatigue. Redistribute volume from a dominant muscle only if they are not. Volume has the ladder.

Why the order matters. Reaching for "she's just built that way" before steps one and two have actually been run is the failure this rule exists to stop. Genetic architecture is the last explanation standing, not the first one reached for.

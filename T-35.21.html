Pain rules and when to refer · T-35.21

Writing up a pain complaint

A pain note follows the intake, in the intake's order, and names any fault from the shared fault vocabulary. It never uses a diagnostic word.

The format, in the intake's order

Onset. An incident, a creep, or she woke up with it. How long she has had it.

Mechanism. One rep felt different from the one before, or it built across the set and settled.

History. Every previous injury, not only the presenting joint.

Context. Stress, a changed split, a deficit, fatigue. Asked directly.

A note that stops at "her knee hurts" has not used it.

Where the note names what a movement looked like, use the shared fault vocabulary. Faults and what you can actually see commits to one name per fault across the whole coaching team. The note never uses a diagnostic word, however informally. The scope rule governs the note exactly as it governs the conversation.

Why it matters. A file is read by whoever covers for you next. It should teach them what you saw, not what you guessed.

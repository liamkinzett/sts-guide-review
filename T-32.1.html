Faults and what you can actually see · T-32.1

A fault has one name across the team

When you write a note, a check-in or a program comment, you use the fault's one canonical name. When you talk to her, you use whatever she understands.

The lookup table at the end of this topic carries all forty-four faults (canonical name), with the hundreds of other phrasings coaches use for them. Every phrase you have heard maps onto one row.

Why it works. Three things become possible that are impossible without it, and none of them is tidiness.

  • You can count. "Rib flare showed up on nineteen movements across the roster this month." Nobody could write that when the same fault had seventeen names.
  • You can hand a client over. A coach reading another coach's history gets the same picture the writer had. This is the one that costs real money when it fails.
  • You can tell improvement from relabelling. A fault that changes name looks like a fault that was fixed and replaced by a new one.

    • A fault name carries a scope. The table's last column names where the fault is not a fault. A few rows carry one. Every other row reads "holds everywhere", which means the fault holds wherever it is visible.

    Two examples show why a scope is needed. "Scapular protraction at lockout", the shoulder blades sliding forward as the arms straighten (scapular protraction), is a fault. But the push-up coaches protraction at the top and forbids pinning the blades. Shoulder elevation is a fault, but the shrug is elevation.

    Never invent an exception a movement has not earned. "Holds everywhere" is a claim too. It says nobody has yet found a movement where this fault is the standard.

    Watch for

    The canonical name leaking into client conversation. "Undeclared scapular bias" is a filing term. She needs "your shoulder blade is doing the work your arm should be doing", which is Cueing's job.

    Say it like this: nothing. This rule is for what you write, not what you say.

    Terms on this page

    canonical name: The one agreed name for a fault that every coach uses in notes, so that two notes about the same thing say the same thing.

    scapular protraction: The shoulder blades sliding forward and out around the rib cage, away from the spine. It happens at the top of a push-up.

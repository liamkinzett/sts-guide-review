Progression · T-10.18

An isolation progresses on the same ladder as a compound

Double progression and the reps-then-load-then-a-set order apply to every movement on the hypertrophy path. It does not matter whether the movement is a compound or an isolation. There is no separate progression model for an isolation.

Where isolations do get treated differently is volume placement, not progression. Volume names small isolated muscles as the place an extra set is cheapest to add, because the whole-body cost there is low. That is a decision about where to spend volume. It sits before this topic. It does not change which lever comes first once the set exists.

Watch for

Reading the cheap-set logic as licence to add load faster on an isolation. The order is still reps, then load, then a set, on every movement this topic governs.

Effort and intensity · T-09.23

True failure has a ceiling set by three constraints

How many sets a session may take to true failure is set by three constraints, not by a count. Once all three hold, the number of failure sets is whatever they leave.

Three constraints on true failure

Never on a compound. The compound floor holds regardless of how many sets the session contains.

One week per block, on isolation work. The phases puts true failure in a single named week. It is not a standing feature of every session.

Only the last working set of an exercise. Rest and intensity techniques attaches an intensifier to the final set so the earlier sets stay comparable. A failure set follows the same logic. Every set after a failure set is performed by a weaker lifter, which degrades working sets you still need to be clean.

Why no count is given. Once a session holds all three, the number of true-failure sets in it varies by phase and by how many isolation movements the session has. A printed number would be either redundant with the constraints or wrong for a session that does not match it.

A worked example. In the block's named failure week, a session holds a squat, a leg press, a leg extension and a leg curl. The squat and the leg press stay at the floor. The leg extension and the leg curl each take their last working set to failure. That is two failure sets, and the constraints decided it.

The phases · T-07.6

A hypertrophy block runs six weeks, extended while it still works

A hypertrophy block runs six weeks by default, and you extend it while overload is still happening. A block that is still working is not a block to end on schedule.

Key figure

value: 6 weeks

unit: default, 3 weeks minimum, no hard maximum

note: End it early on a stall or fatigue. Run it longer while she is still adding load or reps cleanly.

What sits inside a hypertrophy block

The block | Six weeks by default, extended while overload continues, never below three

The week | 15 to 20 hard sets per target muscle for an intermediate, every range covered

The set | Weight chosen toward the stretched position, at 3 RIR falling to 0 in the final week

End it early if progression stalls across consecutive sessions on the main lifts, or fatigue signals fire. Run it longer if she is still adding load or reps cleanly with technique holding (overload).

Never cut a phase below three weeks. If the timeline needs adjusting, extend by a week or two to line up with the next phase. Do not cut this one short.

This is a training block, not her nutrition phase. The Nutrition Manual runs a build for twelve weeks minimum. That build holds several hypertrophy blocks and the deloads between them. Six weeks here does not mean six weeks of eating in a surplus.

Terms on this page

overload: Doing more than last time: more load, more reps or better reps at the same load. It is the signal that tells the muscle to adapt.

Building a session · T-12.13

A short session is built by the same arithmetic

A thirty or forty minute session is not a compressed version of a normal one. It is built from the same rules that build any session, with the time available run first. That holds whether it is two lunch-break days inside a six-day week or the only three sessions a week she has.

Build it in this order

Work out how many slots the time actually allows. Exercise count is still calculated, never looked up. A short window buys fewer slots. Decide the number before deciding what goes in them.

Decide what earns those slots. Compounds first, minimal isolation. Training around life wrote that selection for exactly this situation. It does not change because the constraint is minutes inside a longer week rather than days inside it.

If it still does not fit, check her execution before you blame the window. Only then is the fix a programming one. Cut further down the compressed-week list rather than trying to run a full session in less time.

Variations

STS programs this tool at seven sites: glute, quad, hamstring, lat, scap, calf and root. Every row is the same tool applied to a different site. The standard on this page covers all of them.

The sites

# Quad trigger point / foam roll

sub: Site only

What changes: Nothing. Pin and stretch, two or three points, then leave.

# Root trigger point / foam roll

sub: Site only

What changes: Nothing. The same standard.

# Glute, hamstring, lat, scap and calf

sub: Site only

What changes: Nothing. The detailed hip-to-knee map is written for the outer thigh. Every other site gets the general standard.

It is a short-term sensory tool and not a tissue intervention. It does not break up scar tissue. It does not flush toxins. That must not be softened in delivery, whichever site she is rolling.

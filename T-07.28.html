Test day format depends on what she wants from it

There are three ways to run test day. Pick the one that matches what she wants out of it.

Three formats

# Powerbuilding

sub: All lifts in the final week, spread across the sessions

How it runs: Each lift is tested in the final week, spread across the available sessions.

# General population peaking for the enjoyment of it

sub: One lift per session

How it runs: One lift per session, spread out so each gets a fresh session.

# The full experience

sub: All lifts on a single day, run like a meet

How it runs: All lifts on one day, replicating official powerlifting conditions (mock meet). Attempts, commands, the lot. Some women want the day itself as much as the number.

Test day is the one day she warms up generally. An ordinary session has no general warm-up. Test day is the exception, and Warming up covers it.

Terms on this page

mock meet: A practice competition run in the gym. Attempts, commands and the order of lifts all copy the real day.
